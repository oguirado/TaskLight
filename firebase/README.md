# firebase/

- `firestore.rules`: Firestore security rules (U15). Implements SPEC U15 §3 (B1–B15) + hypotheses H2–H4. Fail-closed deny-by-default; membership via `workspaces/{wsId}.members`; capsule guarded publication (`rev` = prev+1 as int, `writer_uid` = caller, `status` enum, allowlists, string-typed text limits 120/600/120, private tier text-free); digests/templates/ledger per B12–B14, with digest `brief` string-typed. Workspace update is owner-only and validates the incoming doc (`name`+`members` exact keys, `members` is a map, every role in `owner|editor|viewer`, at least one owner) so an owner cannot empty the member set, demote the last owner, or admit an invalid role; workspace create stays self-owner-exact. Status literal list mirrors U05 `CAPSULE_STATUS` (`running|waiting_input|blocked|failed|done|idle`); `attention` is not type-checked (U05 string enum vs spec number hypothesis). Notable emulator-confirmed decisions: `request.resource.data.get('k','') is string` + `.size()` for optional text limits, `keys().hasOnly` + `keys().hasAll` for exact key sets, `members.values().hasOnly([...])` + `'owner' in members.values()` for workspace members, `members.keys().hasOnly([uid])` + `hasAll([uid])` for self-owner workspace creation, `is int` for `rev`, `observed_rev` and ledger counters.
