## Judgement calls (confirm or amend)
- J1 `MODEL_RELAY_LIMITS` key names (FRAME_MAX_BYTES, QUEUE_MAX, MESSAGES_MAX, MAX_TOKENS_MAX, SLACK_MS, LIST_MS, PROBE_MS, LOCAL_GENERATE_MS, REMOTE_GENERATE_MS) are mine; the spec fixes only the values.
- J2 A reset (host `hello` or disconnect) answers queued, not yet forwarded, requests with `host_absent` too (one reply per accepted rid).
- J3 Host replies must match the pending kind and id (health for a generate, or a health `id` that differs, is `bad_reply`); host nack codes must be the 16 U48 codes (a local-only code from the host is `bad_reply`); health `rung` must be 1/2/3/null.
- J4 `ports` in `stats()` counts ports that sent a model_* frame; `dropped` counts invalid frames without a valid rid (including `model_` with no rid via sw_main). Late replies after a reset count as `late`.
- J5 Timeout of a `model_list` answers `timeout` to the page; whether a host `model_cancel` is also sent for a list is not pinned. Cancel of an in-flight list only must not throw.
- J6 Validation precedes the gate: an invalid frame gets `bad_request` even when the relay is not ready. `model_nack` with a rid shaped OK but unknown `t` follows the "invalid frame with valid rid" rule.
- J7 A queued request has its own timer armed at acceptance and times out in the queue with no host cancel.
- J8 Selection get/set work while the host gate is closed and do not use the generate queue; `get` strips `v`; a stored value with any malformed part maps to `{}` as a whole.
- J9 Port close: queued dropped, in-flight cancelled at host, the slot frees when the host's reply (cancelled nack) arrives; the next port's request is forwarded then.
- J10 Page-frame size is measured on the page frame (UTF-8 bytes). Risk for the author, NOT pinned: the host frame carries `m<n>` instead of the page rid, so a page frame at exactly 65,536 bytes with a 1-char rid could become 65,537 bytes at the host (host dies, F3). The test only pins 65,537 `too_large`, bytes-not-chars, and ~60,000 forwarded; consider measuring the rewritten frame.
- J11 `static`: "storage.local only in chrome_ports.ts" requires the literal `storage.local` in `chrome_ports.ts` (red until `createLocalStore` exists); `model_relay.ts` may only import `./types`, `./chrome_ports`, `./limits`.
- J12 The sw_main spies rely on `models.onPortMessage` / `onPortClosed` being looked up on the object at call time (as `agent` is today).
